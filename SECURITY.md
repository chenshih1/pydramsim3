# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

This is a research/educational software package with no network-facing
attack surface; the practical risk is limited to malformed config files or
traces causing crashes (the bundled DRAMsim3 C++ code is not hardened).

Please report issues by opening a GitHub issue
(<https://github.com/chenshih1/pydramsim3/issues>) or, for anything you
consider sensitive, contact the maintainer directly by email
(`chenshi8603@163.com`) before filing a public issue.
